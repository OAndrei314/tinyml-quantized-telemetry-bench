### $\gamma$-weakly $\theta$-up-concavity: A Unified Framework for Non-Convex Optimization Beyond DR-Submodular and OSS Functions

- Source: arXiv CS.AI
- Published: 2026-11-13
- Link: https://arxiv.org/abs/2602.13506
- Matched layers: data_center_energy

We introduce $\gamma$-weak $\theta$-up-concavity, a first-order condition for nonnegative monotone functions in which a scaling function $\theta$ lets the curvature change with the size of the solution. The resulting class strictly contains monotone DR-submodular functions and One-Sided Smooth (OSS) functions.

### A Compact xDAWN-Guided Spatio-Temporal Network with Filter-Bank Convolution for P300 Detection

- Source: arXiv CS.AI
- Published: 2026-11-13
- Link: https://arxiv.org/abs/2611.17101
- Matched layers: market_context

Reliable P300 detection remains difficult because of low response amplitude and signal-to-noise ratio, while practical spellers require accurate character selection with few stimulus repetitions and low computational cost. These results suggest that combining domain-informed spatial and spectral priors with compact neural networks can support efficient P300 decoding for EEG-based BCI communication.

### A Joint LLM and Optimization Agent Solution for Drone Scheduling in Victim Search Missions

- Source: arXiv CS.AI
- Published: 2026-11-13
- Link: https://arxiv.org/abs/2611.16524
- Matched layers: data_center_energy

The system employs an agent at the ground control station (GCS) to coordinate multiple drones over successive search cycles. In each cycle, the agent applies a scheduling policy that combines a large language model (LLM) for reasoning about where to search with an optimizer for determining how to dispatch the drones under energy constraints.
