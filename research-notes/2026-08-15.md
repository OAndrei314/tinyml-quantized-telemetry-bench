### AaLLM: An End-to-End Analog Circuit Design Framework from Topology Generation to Sizing Using Large Language Models

- Source: arXiv CS.AI
- Published: 2026-08-15
- Link: https://arxiv.org/abs/2608.13472
- Matched layers: ai_compute

In this paper, we present AaLLM, an open-source end-to-end multi-agent LLM workflow that takes user specs as input and outputs the appropriate netlist, encompassing both topology generation and circuit sizing. A RAG model is implemented to emulate circuit design expertise using this knowledge base.

### AgenticCANN: Automated Ascend C Operator Generation via Knowledge-Augmented Agentic Evolution

- Source: arXiv CS.AI
- Published: 2026-08-15
- Link: https://arxiv.org/abs/2607.26661
- Matched layers: ai_compute

While large language models (LLMs) have shown promise in automated CUDA kernel generation, the fundamentally different programming model of Ascend C introduces unique challenges that remain unexplored. In this paper, we propose AgenticCANN, a knowledge-augmented agentic evolution framework specifically tailored for automated Ascend C operator synthesis in low-corpus NPU environments.

### $\varepsilon$-MemEvo: Adaptive Cross-Task Memory Transfer for LLM Program Evolution

- Source: arXiv CS.AI
- Published: 2026-08-15
- Link: https://arxiv.org/abs/2608.12522
- Matched layers: market_context

We introduce $\varepsilon$-MemEvo, a framework for cross-task knowledge transfer in LLM program evolution. To avoid negative transfer from semantically mismatched memories, $\varepsilon$-MemEvo uses an adaptive injection gate that decides whether retrieved memories should be injected, and at what intensity.

### A Compositional Theory of Curvature in Probabilistic Circuits

- Source: arXiv CS.AI
- Published: 2026-08-15
- Link: https://arxiv.org/abs/2608.12869
- Matched layers: ai_compute

arXiv:2608.12869v1 Announce Type: cross Abstract: Probabilistic Circuits (PCs) are generative models that support exact inference and, unlike deep neural networks, admit an exact and tractable measure of loss-surface curvature: the trace of the Hessian of the log-likelihood. We show that treating sharpness as a global regularizer can be misspecified for PCs, whose curvature is inherently compositional.
